# sc-inter — 웹 1대1 온라인 미니 축구

브라우저만 있으면 두 사람이 같은 경기를 실시간으로 즐길 수 있는 미니 축구 게임이다.
방을 만들면 6자리 코드와 초대 링크가 나오고, 상대가 접속하면 바로 킥오프한다.
**3대3**(사람 1명 + AI 동료 2명)으로 겨루며, 드리블·질주·개인기·패스를 모두 서버가 판정한다.

## 빠른 시작

```bash
pnpm install
pnpm build          # 웹 번들 + 서버 컴파일
PORT=8787 pnpm start
# http://localhost:8787
```

개발 중에는 두 프로세스를 따로 띄운다.

```bash
pnpm dev:api        # 8787 포트, WebSocket + API
pnpm dev            # 5175 포트, Vite 개발 서버 (ws 는 8787 로 프록시)
```

## 조작

| 동작 | 키 |
| --- | --- |
| 이동 | 방향키 ← ↑ → ↓ |
| 패스 | `S` |
| 슛 | `D` (누르면 충전, 떼면 발사) |
| 달리기 | `E` |
| 개인기 | `Shift` + 방향키 (앞 스텝오버 / 좌우 페인트 / 뒤 드래그백) |
| 태클 | `Q` |
| 조작 선수 바꾸기 | `C` |

## 구성

- `app/api` — Node 22 + TypeScript. 60Hz 권위 시뮬레이션(미터 단위 56m × 34m 경기장, 3대3), 20Hz 상태 브로드캐스트, 드리블·질주·개인기·패스·AI 선수 판정, 정적 웹 서빙, `/healthz`, graceful shutdown.
- `app/web` — React + Vite + Three.js. 실제 사람 비율(키 1.8m)의 3D 선수와 구장을 그린다.

자세한 내용은 [`AGENTS.md`](AGENTS.md) 와 [`docs/`](docs/) 를 참고한다.
