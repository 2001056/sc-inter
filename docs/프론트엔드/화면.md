# 화면

## 디자인 기준

- 스타일은 Modernist 한 갈래만 쓴다(shadcn 혼용 금지). 이모지 아이콘을 쓰지 않고, 색·간격·글자 크기는 CSS 변수(`app/web/src/styles.css` 의 `:root`)로만 정의한다.
- 어두운 잔디색 배경 위에 라임 계열 강조색. 본문 글꼴은 시스템 산세리프, 숫자(점수·시계)는 `tabular-nums`.
- 반응형: 720px 미만에서는 세로 배치로 접히고 모바일 터치 컨트롤이 나타난다.

## 화면 구성

### 1. 로비 (`LobbyView`)

- 닉네임 입력(1~12자)
- `방 만들기` / `코드로 참가` / `혼자 연습`
- 초대 링크에 `?room=CODE` 가 있으면 코드 칸이 자동으로 채워진다.
- 조작 설명과 규칙 요약을 항상 보여준다.

### 2. 대기 (`waiting`)

- 6자리 코드 크게 표시 + `코드 복사` / `초대 링크 복사`
- "상대를 기다리는 중" 안내

### 3. 경기 (`MatchView`)

- 상단 스코어보드: 왼쪽 닉네임 · 점수 · 남은 시간 · 오른쪽 닉네임
- 가운데 Canvas 경기장 (논리 1050×640을 비율 유지로 축소, 내 선수는 항상 파란색 테두리로 강조)
- 하단 조작 안내, 연결 상태(지연 ms), `나가기`
- 카운트다운·득점·경기 종료는 경기장 위 오버레이로 알린다.
- 모바일에서는 화면 아래 왼쪽 조이스틱, 오른쪽 슛 버튼이 나타난다.

### 4. 종료 (`ended`)

- 승/패/무승부와 최종 점수
- `재경기`(상대 준비 상태 표시) / `나가기`

## 접근성·명료성

- 모든 버튼은 버튼처럼 보이게 한다(배경·테두리·커서·포커스 링).
- 상대 이탈·연결 끊김·재접속은 경기장 위 배너로 한국어 문장으로 알린다.
