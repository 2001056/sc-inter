# 시뮬레이션 (권위 모델)

## 권위

- 서버만 경기 상태를 바꾼다. 브라우저는 입력만 보내고, 받은 스냅샷을 그린다.
- 브라우저는 예측(prediction)을 하지 않는다. 대신 스냅샷 두 개 사이를 보간해 부드럽게 그린다(렌더 지연 약 100ms).
- 따라서 두 브라우저가 보는 점수·시간·공 위치는 같은 서버 상태에서 나온다.

## 루프

| 항목 | 값 |
| --- | --- |
| 물리 틱 | 60Hz 고정 (`dt = 1/60`) |
| 브로드캐스트 | 20Hz (3틱마다) |
| 경기 시간 | `playing` 단계에서만 줄어든다 |

틱은 `setInterval` 의 실제 경과 시간을 누적해 처리하므로 타이머가 밀려도 시뮬레이션 속도는 일정하다(한 번에 최대 5틱까지 따라잡는다).

## 물리

- 선수: 반지름 21, 가속 2600, 최고 속도 385, 항력 6.2.
- 공: 반지름 12, 항력 0.62, 최고 속도 1450, 벽 반발 0.72.
- 선수-공 충돌은 질량비(선수 3.2 : 공 1)를 쓴 임펄스 해법이고, 겹침은 위치로 밀어 분리한다.
- 선수-선수 충돌은 서로 밀어내며 속도를 교환한다.
- 슛: `Space` 를 누르는 동안 0~0.6초 동안 힘이 차오르고, 떼면 `선수 → 공` 방향으로 임펄스를 준다. 힘은 380~760이고 선수 속도의 45%가 더해진다. 쿨다운 0.34초.

## 득점

- 공의 중심이 골라인(x=0 또는 x=1050)을 반지름만큼 넘고 골문 세로 범위 안이면 득점이다.
- 득점 즉시 `goal` 단계로 바뀌고 1.2초 뒤 킥오프 카운트다운으로 넘어간다.

## 봇 (연습 모드)

- 같은 시뮬레이션 안에서 입력만 만들어내는 단순 AI다. 공과 자기 골문 사이를 잡는 위치로 이동하고, 사거리에 들어오면 상대 골문 방향을 보고 슛한다.
- 반응 지연 120ms, 조준 오차를 주어 사람이 이길 수 있게 한다.
