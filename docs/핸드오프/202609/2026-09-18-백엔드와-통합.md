작성: 백엔드/통합 담당. 3D 프런트(`app/web`, `docs/프론트엔드`)는 별도 담당이 소유한다.

## 1. 무엇을 했나

1. 빈 저장소 `github.com/2001056/sc-inter` 에 프로젝트를 새로 세웠다(`app/api` + `app/web` 워크스페이스, 한글 `docs/`).
2. 서버 권위 시뮬레이션과 WebSocket 실시간 서버를 만들었다.
3. 요구가 두 번 바뀌어 그때마다 계약과 구현을 갱신했다.
   - 1차: 1대1 미니 축구(2D Canvas 전제)
   - 2차: 실제 사람 비율 3D + 개인기 → 미터 단위 좌표계, `facing`/`anim`/쿨다운을 wire 에 추가
   - 3차: **3대3(사람 1 + AI 동료 2)**, 슛/패스 분리, 달리기 버튼, 방향별 개인기
4. 배포 구성(`Dockerfile`, `compose.yaml`)과 상시 개발 서버 운용 절차를 만들었다.

## 2. 결정과 이유

| 결정 | 이유 |
| --- | --- |
| 입력에 **키를 싣지 않고 의도만** 보낸다 | 사용자가 키 매핑을 세 번 바꿨다. 의도(`shoot`/`pass`/`sprint`/`skillDir`/`tackle`/`switchPlayer`)만 계약에 두면 키가 바뀌어도 서버는 그대로다 |
| 개인기는 `skillDir`(월드 벡터)만 받고 **서버가 판정** | 프런트는 `SkillKind` 를 직접 보내자고 제안했지만, 판정이 클라이언트로 새면 서버 권위가 깨진다. 대신 attack-relative 규칙을 문서에 못 박았다 |
| 이동 개인기 3종은 쿨다운 공유, 태클은 별도 | 개인기 난사를 막고 태클은 위험 부담(0.9초 넘어짐)이 따로 있다 |
| 조작 선수 전환은 보수적으로 | 사람이 키를 누르는 중에 선수를 빼앗으면 조작감이 무너진다. 독립 검증에서 실제로 이 문제가 4건의 실패로 드러났다 |
| 패스 중에는 전환 보류 | 패스 → 수신자 조작이라는 흐름이 중간 전환 때문에 끊겼다 |
| AI 는 사람과 같은 `InputState` 를 만든다 | 규칙이 두 갈래로 갈라지지 않는다. 연습 모드는 상대 팀 전원을 같은 AI 가 맡는다 |
| 좌표를 미터로 | 3D 렌더러가 월드 단위를 그대로 쓰고 사람 비율(키 1.8m)이 살아난다 |

### 독립 검증에서 나온 실패 4건 — 두 층으로 나눠 기록한다

독립 검증 담당은 실패 4건을 **테스트 fixture 문제**로 분류했다. 자동 전환이 일어난 뒤 fixture 가 여전히 원래 선수를 측정하고 있어서, 측정 대상이 어긋난 채로 단언이 깨진 것이다. 이 진단은 맞다. 테스트를 고쳐도 통과시킬 수 있었다.

그런데 같은 로그를 조작감 관점에서 보면, 사람이 키를 누르고 있는 동안 조작 선수를 빼앗기는 동작 자체가 게임으로서 잘못이었다. 그래서 테스트가 아니라 **동작을 고치는 쪽**을 골랐다.

| 층 | 내용 |
| --- | --- |
| 진단 (검증 담당) | 자동 전환 후 fixture 가 이전 선수를 계속 측정 → 패스 수신 전 전환, 개인기 도중 전환, 스태미나 오차로 나타남 |
| 결정 (백엔드) | fixture 를 고치는 대신 자동 전환 규칙을 보수적으로 바꿨다. 입력 중·공 6m 이내에는 전환 금지, 패스 비행 중 보류. 테스트 파일은 손대지 않고 그대로 통과 |

즉 **버그 신고는 fixture 계층, 실제 수정은 UX 계층**이다. 둘을 같은 것으로 적지 않는다.

### E2E 중 알게 된 것

- 백그라운드 탭은 브라우저가 `requestAnimationFrame` 을 늦춰서 HUD 가 멈춘 것처럼 보인다. 화면을 다시 보면 즉시 따라잡고 서버 상태는 정상이다. 자동화로 확인할 때 이걸 버그로 오해하기 쉽다.
- 재접속 토큰이 메모리에만 있어 새로고침하면 `resume` 이 안 된다. 필요하면 프런트가 `sessionStorage` 에 넣어야 한다(서버는 30초 유예로 준비되어 있다).

## 6. 함정

- `node --experimental-strip-types` 는 **파라미터 프로퍼티**(`constructor(private x: T)`)를 못 읽는다. 테스트가 곧바로 깨지므로 필드를 따로 선언한다.
- 클래스 필드를 `timeLeftMs = MATCH.durationMs` 로 두면 `as const` 상수의 리터럴 타입(`120000`)이 그대로 굳는다. `timeLeftMs: number = …` 로 적는다.
- 개발 서버를 끌 때 `pkill -f node` 같은 넓은 패턴은 다른 프로젝트까지 잡는다. `logs/server-8787.pid` 의 PID 만 종료한다.
- 물리 상수를 고칠 때 가속(48)이 항력(4.2) 대비 낮으면 최고 속도 설정이 아예 걸리지 않는다. 달리기/질주 차이가 사라지는 형태로 드러난다.
