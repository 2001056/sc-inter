## 후속 수정 (task `task_848ee52c8cd3`, dispatch `ctx_b1163caf351f`)

### 1. 끄기·숨김 뒤 예약된 소리가 이어 울리던 문제

- 원인: `setEnabled(false)`·`setHidden(true)` 가 `AudioContext.suspend()` 만 했다. suspend 는
  컨텍스트 시계도 세우므로, 이미 예약된 종료 휘슬(0.72초 뒤 세 번째 소리)·관중 함성(1.9초)이
  다시 켰을 때 멈춘 자리부터 이어 울렸다.
- 수정(`game/audio.ts`): 울리는 중이거나 예약된 소리를 `Set<Voice>` 로 들고 있다가, 끄기·숨김·
  dispose 때 `silenceAll()` 로 발음원 `stop()` → 체인 전체 `disconnect()` → 목록 비우기를 한다.
  `onended` 를 떼어 내 늦게 오는 종료 알림이 카운터를 건드리지 않고, 정리는 멱등이다. 컨텍스트는
  닫지 않고 멈추기만 하므로 사용자 동작으로 깨운 상태와 설정은 그대로다. 다시 켠 직후 첫 소리가
  간격 제한에 걸리지 않게 간격 기록도 비운다. 정상적으로 끝난 소리는 다시 멈추지 않는다.
- 테스트(`test/audio.test.ts`) 5개 추가: 끄기/숨김 각각 "예약된 종료 휘슬+함성 → 멈춤·끊김 →
  다시 켬 → 새 소리 정상, 옛 발음원은 다시 안 건드림", 연속 끄기·숨김·dispose 멱등(멈춤 1회,
  close 1회, 늦은 onended 무해), 정상 종료 소리는 stop 안 함, resume·suspend·close 가 모두
  거부돼도 unhandled rejection 0.
- 대조군: `setEnabled(false)` 의 `silenceAll()` 을 잠시 빼면 끄기 테스트가 실패하고, 되돌리면
  통과하는 것을 확인했다.
