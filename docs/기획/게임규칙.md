# 게임 규칙

## 경기 형식

- 1대1. 한 사람이 선수 한 명을 조작한다.
- 경기 시간 120초. 시간이 다 되면 점수가 높은 쪽이 승리하고, 같으면 무승부다.
- 킥오프는 3초 카운트다운 뒤에 시작한다. 카운트다운 동안 입력은 무시된다.
- 득점하면 1.2초 세리머니 후 양쪽 선수와 공이 제자리로 돌아가고 다시 3초 카운트다운.

## 경기장

- 논리 좌표 1050 × 640. 좌우 끝 중앙에 높이 208의 골문이 있다.
- 왼쪽 선수는 왼쪽 골문을 지키고 오른쪽 골문에 넣어야 득점한다.
- 공은 위·아래 벽과 골문을 뺀 좌우 벽에서 튕긴다.

## 조작

| 동작 | 입력 |
| --- | --- |
| 이동 | `W` `A` `S` `D` / 방향키 / 모바일 조이스틱 |
| 슛 | `Space` / 모바일 슛 버튼. 누른 시간만큼 힘이 차오른다(최대 0.6초) |

- 슛은 선수 중심에서 공 중심 방향으로 힘을 준다. 공이 사거리 밖이면 헛발질(쿨다운만 소모).
- 슛 쿨다운 0.34초.

## 방과 참가

- 방을 만들면 6자리 코드(예: `K7Q2MD`)와 초대 링크 `?room=K7Q2MD` 가 생긴다.
- 한 방에는 두 명까지 들어간다. 세 번째 참가 시도는 `ROOM_FULL` 로 거절한다.
- 상대가 나가면 즉시 안내가 뜬다. 연결이 끊긴 경우 30초 동안 자리를 지키고, 같은 브라우저 탭은 자동으로 재접속한다.
- 경기가 끝나면 양쪽이 모두 "재경기"를 누를 때 새 경기가 시작된다.

## 연습 모드

- 혼자서 컴퓨터 상대와 같은 규칙으로 연습할 수 있다. 서버의 같은 시뮬레이션을 쓰고, 상대 선수만 봇이 조작한다.
- 멀티플레이가 기본이고 연습 모드는 보조 수단이다.
