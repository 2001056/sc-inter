# 게임 규칙

## 경기 형식

- 1대1. 한 사람이 실제 사람 비율의 선수 한 명을 조작한다.
- 경기 시간 120초. 시간이 다 되면 점수가 높은 쪽이 승리하고, 같으면 무승부다.
- 킥오프는 3초 카운트다운 뒤에 시작한다. 카운트다운 동안 입력은 무시된다.
- 득점하면 1.8초 세리머니 후 양쪽 선수와 공이 제자리로 돌아가고 다시 3초 카운트다운.

## 경기장

- 실제 크기 기준의 평면 좌표(미터)를 쓴다. 길이 64m × 폭 42m, 골대 폭 7.32m.
- `x` 는 길이 방향(0 = 왼쪽 골라인, 64 = 오른쪽 골라인), `y` 는 폭 방향이다. 3D 렌더러는 `(x, y)` 를 바닥 평면 `(x, z)` 로 매핑한다.
- 왼쪽 선수는 왼쪽 골문을 지키고 오른쪽 골문에 넣어야 득점한다.
- 공은 터치라인과 골문 밖 골라인에서 튕긴다.

## 선수 능력치

| 항목 | 값 |
| --- | --- |
| 키 / 충돌 반지름 | 1.82m / 0.45m |
| 달리기 | 6.6 m/s |
| 스프린트 | 9.1 m/s (스태미나 소모) |
| 슛 세기 | 9 ~ 26 m/s (0.7초까지 충전) |

## 조작

| 동작 | 입력 |
| --- | --- |
| 이동 | `W` `A` `S` `D` / 방향키 / 모바일 조이스틱 |
| 스프린트 | `Shift` (누르는 동안, 스태미나 소모) |
| 슛 | `Space` — 누른 시간만큼 세진다 |
| 스텝오버(개인기) | `J` 또는 `Q` — 옆으로 치고 나가며 가까운 상대를 흔든다. 쿨다운 3.2초 |
| 슬라이딩 태클 | `K` 또는 `E` — 앞으로 미끄러지며 공을 걷어낸다. 끝나면 0.9초 못 움직인다. 쿨다운 5.2초 |

- 슛은 선수 중심에서 공 중심 방향으로 힘을 준다. 공이 사거리 밖이면 헛발질(쿨다운만 소모).
- 공이 1.5m 안에 있고 움직이는 중이면 자동으로 **볼 컨트롤(드리블)** 이 걸려 공이 발 앞 0.85m 에 붙는다. 스프린트 중에는 컨트롤이 느슨해져 공이 크게 튄다.
- 스텝오버로 상대를 흔들면 상대는 0.62초 동안 속도가 45%로 떨어진다.

## 스태미나

- 1.0에서 시작해 스프린트 중 초당 0.26 줄고, 그 외에는 초당 0.14 회복한다.
- 스텝오버는 0.1, 슬라이딩은 0.16을 쓴다. 0.06 아래로는 스프린트할 수 없다.

## 방과 참가

- 방을 만들면 6자리 코드(예: `K7Q2MD`)와 초대 링크 `?room=K7Q2MD` 가 생긴다.
- 한 방에는 두 명까지 들어간다. 세 번째 참가 시도는 `ROOM_FULL` 로 거절한다.
- 상대가 나가면 즉시 안내가 뜬다. 연결이 끊긴 경우 30초 동안 자리를 지키고, 토큰으로 재접속하면 점수와 시간이 이어진다.
- 경기가 끝나면 양쪽이 모두 "재경기"를 누를 때 새 경기가 시작된다.

## 연습 모드

- 혼자서 봇 상대와 같은 규칙으로 연습할 수 있다. 서버의 같은 시뮬레이션을 쓰고 상대 입력만 봇이 만든다.
- 멀티플레이가 기본이고 연습 모드는 보조 수단이다.
